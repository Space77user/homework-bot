Telegram-бот для удобного управления школьным расписанием и домашними заданиями. Создан для нашего класса, чтобы всегда знать, что задали, и иметь под рукой готовые решения.

## Функционал
 Расписание по дням недели (меню с кнопками)
 Добавление заданий (текстом или фото)
 Добавление готовых решений к заданиям
 Автоматическая рассылка расписания на завтра в группу в 20:00
 Автоочистка старых заданий по пятницам
 Приватность (работает только в белом списке)

## Технологии
 **Бот**: Node.js, grammY
 **База данных**: SQLite (better-sqlite3)
 **Планировщик**: node-schedule

## Запуск проекта

1. Клонировать репозиторий:  
   `git clone https://github.com/Space77user/domashka-bot.git`

2. Установить зависимости:  
   `npm install`

3. Создать файл `.env` с переменной:  
   `BOT_TOKEN=ваш_токен_от_BotFather`

4. Запустить бота:  
   `npm start`
